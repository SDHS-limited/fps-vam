# Stage 1 - Gravity Prototype

## 실행

Unity에서 `Assets/Scenes/Stage 1 - Gravity Prototype.unity`를 열고 Play한다.
메인 메뉴의 기존 Start는 계속 원본 Stage 1을 연다. 프로토타입을 빌드 목록에 등록하거나 메뉴 기본 경로로 바꾸지 않았다.

## 이번 구현 범위

기획 V2.0의 Gravity Shift와 Gravity Pulse 프로토타입이다. Anchor, Flux, ArenaDirector는 이번 범위에 포함하지 않았다.

- 화면 중앙으로 Ground 태그가 있는 큐브 면을 조준하고 E 키를 누르면 해당 면 방향으로 중력을 바꾼다.
- 비용은 없다. 키 반복과 급격한 연속 반전을 억제하는 0.3초 입력 간격만 있다.
- 기존 근접 면 자동 중력 전환은 GravityShiftMotor가 활성화된 플레이어에서만 중단된다.
- 6면 방향으로 중력을 즉시 설정한다. 물리 캡슐은 목표 면에 즉시 정렬하고, 카메라만 별도 피벗에서 90도 약 0.18초, 180도 약 0.28초의 감속 곡선으로 회전한다. 초당 1100도 상한을 둔다.
- 180도 전환 회전축을 명시하여 바닥-천장 반전이 불안정해지지 않게 한다.
- 이동 관성을 새 면으로 회전시키되 전환 순간 속도 상한 14m/s를 둔다. 위치를 순간이동시키지 않는다.
- 조준 가능한 면/현재 면/회전 중 상태를 HUD에 표시한다. 일시정지·커서 표시·게임오버 중에는 HUD와 입력을 숨긴다.
- 적/일반 장애물 뒤의 면으로 전환하지 않는다. 회복/시간/능력 아이템은 면 조준을 가리지 않는다.
- 이 씬에서만 중력 가속도 22, 점프 8로 설정하고 타이머 카운트다운을 비활성화했다.
- 편집기에서 빌드에 등록하지 않은 테스트 씬도 Restart 버튼으로 다시 열 수 있다.

`GravityShiftMotor`는 새 씬의 Player에만 붙였다. 원본 Stage 1 씬 파일 SHA256은 전후 동일했다:
`488A0D1F329A6A274A4D8DA3CCE65430A40670C8411934244F525842000AB160`

## 검증

MCP Play Mode에서 명시적 Physics.Simulate 고정 스텝으로 6면을 검사했다.

- ±X, ±Y, ±Z 각각 180스텝 후 해당 Ground 면 근처에 착지했다.
- 각 면에서 Rigidbody의 up과 면 법선 내적이 1.0000이었다.
- 일반 장애물과 빈 공간을 조준한 전환은 거부됐다.
- 점프 속도 8, 대시 접선 속도 27.9, 대시 중 법선 속도 0을 확인했다.
- 일시정지 중 전환 거부, Restart 후 프로토타입 씬 유지/체력 초기화/타이머 비활성화를 확인했다.
- 최종 컴파일 및 콘솔 오류 없음. 실제 사용자의 카메라 편안함과 입력 감각은 후속 플레이테스트가 필요하다.

## 후속 중력 전환 감각 튜닝

- 전환 직후 새 면으로 최대 12m/s의 초기 속도를 준다. 가까운 면은 거리에 맞춰 속도를 줄이고, 이동 중 새 중력 방향 속도는 18m/s로 제한한다.
- 캡슐이 회전 중 벽·모서리와 접촉하며 카메라 자세가 흔들리지 않도록 물리 몸체와 시점 회전을 분리했다. 마우스 시점 회전은 그대로 유지한다.
- 카메라는 전환과 착지에 짧은 FOV 반응을 주고, 전용 전환·착지 효과음을 재생한다. 전체 화면 섬광은 추가하지 않았다.
- 위의 기존 물리 검증 결과는 최초 프로토타입 기준이다. 감각 튜닝 후 C# 프로젝트 빌드는 오류 없이 통과했으며, Unity 플레이 모드에서의 6면 이동과 체감 확인은 다시 필요하다.

## Gravity Pulse

- 기존 Push 키(기본 마우스 오른쪽 버튼)로 조준 방향 8m에 반경 2.5m 충격파를 발사한다. 벽과 장애물 뒤의 적은 맞지 않는다.
- 재사용 대기시간은 7초이며, 빗나가도 소모된다. 화면 아래쪽에 남은 시간을 표시한다.
- Runner는 직접 피해 12를 받고 22m/s로 밀린다. 벽과 충돌하면 피해 180을 한 번 받는다. 현재 일반 총알 피해 75의 약 2.4발에 해당한다.
- Brute는 적 컴포넌트의 isBrute를 켜거나 Brute 프리팹을 스포너에 연결하면 힘이 25%로 줄고 0.35초 경직된다. 현재 Stage 1 씬의 Brute 프리팹 슬롯은 비어 있다.
- 짧은 청색 파동, 카메라 반응과 전용 효과음을 재생한다. 적과 벽의 충돌은 적의 Rigidbody 충돌로 판정한다.
- Play Mode에서 Runner의 직접 피해·속도·벽 충돌 처치, Brute의 감소된 속도, 즉시 재사용 차단을 확인했다.

## 후속

1. 마우스로 벽/천장을 선택하며 회전 속도와 관성 유지 정도를 실제 플레이로 조절.
2. Gravity Pulse의 범위·벽 충돌 타이밍과 Brute 체감을 플레이테스트로 조절.
3. 상대 속도/중복 피해 간격을 검증한 충돌 피해 추가.
4. Anchor와 라운드 구성을 별도 단계로 확장.
